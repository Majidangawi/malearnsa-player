Catalog OS · Setup guide

Set up the Beyond Catalog OS operator on your computer

One session, about 45 minutes, done together. At the end, Claude on this computer runs the catalog website: window products, imports from links and spreadsheets, hiding products, publishing. Every command, link and prompt is on this page.

Before you start

Bring these to the session:

  • The folder zip beyond-catalog-operator.zip (Majid brings it on a USB stick or a link).
  • The owner's Google account and password (the one that will own the catalog later).
  • A GitHub account for the owner. If none: create one at github.com/signup during step 5.
  • A Claude account with a paid plan (Pro or Max) at claude.ai. Claude Code needs it.
  • Admin rights on the computer (to install tools).
Legend: Claude does it automatically · Owner clicks or types · Majid supplies something only he has.
1

Install the tools

Owner Open Terminal (Mac: Spotlight → type "Terminal"). Paste each block and press Enter. Say yes to any prompt.

1a. Homebrew (Mac package manager) and Git

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
xcode-select --install

On Apple Silicon the installer ends with two lines starting echo … and eval … to add brew to your PATH. Paste those two lines too, then close and reopen Terminal.

1b. GitHub CLI, Node, Python

brew install gh node python@3.12

1c. clasp (Google Apps Script tool) and the Excel helper

npm install -g @google/clasp
pip3 install openpyxl

1d. Claude Code

curl -fsSL https://claude.ai/install.sh | bash

Alternative: npm install -g @anthropic-ai/claude-code. Docs: docs.claude.com → Claude Code.

Check — every line prints a version:
git --version && gh --version && node --version && python3 --version && clasp --version && claude --version

Windows: install Git, GitHub CLI, Node LTS, Python 3.12 (tick "Add python.exe to PATH"), then in PowerShell: npm install -g @google/clasp @anthropic-ai/claude-code and pip install openpyxl. Use PowerShell wherever this page says Terminal.

2

Activate Claude on this computer

Owner In Terminal:

claude

Claude Code opens and asks you to log in. Choose Claude account, a browser opens, sign in with the owner's Claude account, come back to Terminal. Type /exit to leave for now.

Check — claude --version prints a version and the login step does not repeat.
3

Put the folder in place

Majid hands over the zip. Owner unzips it into the home folder:

mkdir -p ~/beyond-catalog && cd ~/beyond-catalog
unzip ~/Downloads/beyond-catalog-operator.zip -d ~/beyond-catalog
chmod +x tools/bf tools/bf.py
ls
Check — you see CLAUDE.md MIGRATION.md ONBOARDING.md README.md apps-script config docs tools (and a hidden .claude folder).
4

Open the folder in Claude Code and say "set up"

cd ~/beyond-catalog && claude

When Claude Code is open, type exactly:

Say to Claudeset up

Claude reads CLAUDE.md, opens ONBOARDING.md and walks you through steps 5 to 9 below, one at a time. It runs the commands itself and asks you only for browser logins and the three links. If Claude asks permission to run tools/bf or gh, choose Yes, and don't ask again.

If Claude instead asks "what would you like to do", say: Follow ONBOARDING.md step by step, starting at step 1.

5

Log into GitHub

Claude runs:

gh auth login

Owner answers the questions: GitHub.com → HTTPS → authenticate Git: Yes → Login with a web browser. Copy the 8-character code, press Enter, paste it in the browser, authorize.

Check — gh auth status shows "Logged in to github.com account <owner's username>".

Google login for clasp (clasp login) is only needed on migration day. Claude will skip it now.

9

Bookmarks for the owner

  • Admin page: the Apps Script URL from step 6 followed by ?page=admin&key= and the admin key. Claude prints the full link in the terminal on request: "print my admin link". Keep it private: the link is the password.
  • The sheet: link above.
  • The site: malearnsa.com/beyond-fmcg (after migration: the owner's domain).
  • Publish history: gh run list -R Majidangawi/malearnsa --workflow=beyond-catalog.yml or the repo's Actions tab.
  • Manuals: in the folder, docs/manual-en.md and docs/manual-ar.md. Ask Claude: "open the manual".

Setup is complete. Claude writes the summary into .migration-progress.md in the folder.

11

Migration day (later, together)

Same folder, one prompt:

Say to Claudemigrate

Claude follows MIGRATION.md step by step with you. What the owner needs ready that day:

  • Google account (Workspace recommended: 1,500 emails/day instead of ~100). Claude will run clasp login for it.
  • GitHub account (done in step 5).
  • Access to the domain's DNS, to add catalog.<domain>.
  • About 2 hours.

What happens, in order: copy the sheet into the owner's Drive → push the script and authorise it (two clicks) → deploy the web app → new GitHub repo with the site → Pages + domain → secrets and the publish token → settings review → purge test data → full end-to-end test → remove Majid's access → rotate the key. At the end, Claude re-runs step 6 with the owner's own links.
