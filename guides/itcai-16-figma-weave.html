Figma Weave: بناء سير عمل كامل

  • Figma Weave
  • Node Based
  • LLM + Image + Upscale + Video
آخر تحديث: سبتمبر ٢٠٢٦

Figma Weave (اسمه السابق Weavy) هو مساحة تجمع كل ما تعلمناه في نظام واحد: LLM يكتب البرومبت، نموذج الصور ينتج، Upscaler يرفع الجودة، نموذج الفيديو يحرّك. كل هذا بضغطة زر واحدة.

تحديث سبتمبر ٢٠٢٦

الفيديو مسجّل في أبريل ٢٠٢٦، والفكرة نفسها ما تغيّرت. اللي تحرّك: الاسم الرسمي اليوم Figma Weave وبيته weave.figma.com١٢، و Freepik صارت كلها اسمها Magnific٣، ونماذج الفيديو داخل Figma Weave صارت أحدث٤، و OpenAI ناوية توقف الـ Custom GPTs في ديسمبر ٢٠٢٦٥. التفاصيل تحت في مكانها.

٠١سير العمل الكامل: من فكرة لفيديو جاهز

  1. الفكرة

    INPUT

    Prompt Node

    تكتب وصفاً بسيطاً، مو برومبت احترافي. مثال: "man in a black suit" أو بالصوت عبر Wispr Flow٦. الـ Node يستقبل هذا الوصف ويمرره للـ LLM.

  2. كتابة البرومبت

    ChatGPT / Claude

    LLM Node

    الـ LLM يأخذ وصفك البسيط ويحوّله لبرومبت احترافي بتقسيمتك الخاصة: Image Type و Camera Angle و Lighting، وغيره. الـ System Prompt داخل الـ Node يعمل كـ Custom GPT كامل.

    محدّث في Figma Weave اسم هذا النود Run Any LLM: تختار النموذج اللي تبيه من القائمة، وتعطيه تعليماتك٧٨.

  3. توليد الصورة

    Nano Banana 2 / Pro

    Image Node

    البرومبت المكتوب من الـ LLM يدخل مباشرة لنموذج توليد الصور. النتيجة: صورة بجودة برومبت احترافي، بدون ما تكتب حرفاً واحداً من البرومبت بيدك.

  4. رفع الجودة

    Magnific Precision ×2

    Upscale Node

    الصورة تدخل Magnific مباشرة بعد التوليد. تطلع بضعف الحجم وتفاصيل أوضح، جاهزة للسوشيال أو التسليم. كل هذا تلقائياً بدون تدخل.

    محدّث النود اليوم اسمه Magnific Precision Upscale V2، وتحكّمه الأساسي في التفاصيل والحبيبة٩.

  5. توليد الفيديو

    Kling / Seedance

    Video Node

    بعد مراجعة الصورة وكتابة برومبت الحركة، الصورة تدخل لنموذج الفيديو. الشخصية ثابتة، الأبعاد ثابتة، الواقعية موجودة. النتيجة: فيديو من صورة واحدة.

    محدّث داخل Figma Weave اليوم تلقى Kling 3 و Seedance 2.0، والاثنين يقبلون أول فريم وآخر فريم ويقدرون يولّدون صوت مع الفيديو٤، وانضاف لهم Seedance 2.5١٠.

٠٢System Prompt داخل Figma Weave: الفرق الحقيقي

كيف تبني Custom GPT داخل الـ Node

نود الـ LLM في Figma Weave يقبل System Prompt كامل١١، نفس فكرة الـ Custom Gem والـ Custom GPT. تضع فيه شخصية الـ LLM، وطريقة تفكيره، وتقسيمة البرومبت المطلوبة، وما لا يجب أن يفعله. النتيجة: كل ما تكتب وصفاً بسيطاً، يخرج برومبت بأسلوبك أنت تحديداً، تلقائياً وبدون تعديل يدوي.

تحديث

OpenAI وقّفت إنشاء GPT جديد على الحسابات الشخصية١٢، وحسب جدولها الحالي الـ Custom GPTs الموجودة تتوقف في ١١ ديسمبر ٢٠٢٦، واللي صمّمها يقدر ينقلها لـ Plugin، والتعليمات اللي فيها تصير Skill٥. أما الـ Gems في Gemini فلسه موجودة١٣.

والفكرة اللي يعلّمك إياها الدرس ما تغيّرت: تعليمات ثابتة تحدد شخصية النموذج وطريقة شغله، وهذا بالضبط اللي تكتبه في الـ System Prompt داخل النود.

٠٣إعدادات مهمة تعرفها في Figma Weave

Temperature

كل ما زاد، شطح الـ LLM بعيداً عن وصفك. كل ما قل، التزم بالتعليمات بدقة.

Credits Per Run

كل نموذج له تكلفة. Nano Banana 2 أرخص، Pro أغلى. احسب الكريدتز قبل تشغيل النظام الكامل.

محدّث Nano Banana Pro يكلّف تقريباً ضعف Nano Banana 2٢، وفيديو Kling 3 ياخذ من ٦٠ لين ٤٤٠ كريدت حسب المدة والجودة٤. تكلفة أي نود تبان لك فوق يمين الشاشة لما تضغط عليه١٤، والخطة المجانية فيها ١٥٠ كريدت بالشهر٢.

Resolution & Size

تحدد Aspect Ratio في نود الصورة والفيديو: ١:١، ١٦:٩، ٩:١٦ حسب الاستخدام النهائي.

Magnific Settings

Scale Factor, Sharpen, Ultra Detail, Smart Grain: كل إعداد يؤثر في الطابع النهائي للصورة.

محدّث معامل التكبير يبدأ من ×2 ويوصل لين ×16، وفي V2 صار فيه كمان Flavor تختار منه: Sublime للصور الفنية والرسومات، أو Photo للصور الفوتوغرافية، أو Photo Denoiser للصور اللي فيها نويز أو متصوّرة في إضاءة ضعيفة١٥.

Grain Control

تحكم في مقدار الحبيبة في الصورة. Grain عالٍ = طابع فلمي. منخفض = صورة نظيفة حديثة.

Run All Nodes

تشغيل كل النظام بضغطة زر واحدة، والأفضل بعد مراجعة نتيجة الصورة أولاً قبل إضافة الفيديو.

أرقام الكريدت بتاريخ ٢٤ سبتمبر ٢٠٢٦ وتتغيّر، فشيّك على التكلفة داخل Figma Weave قبل ما تشغّل.

٠٤ما طلع من ضغطة زر واحدة

من وصف بسيط لفيديو جاهز للتسليم

  • وصف بسيط دخل النظام، والـ LLM كتب برومبتاً احترافياً بالتقسيمة الكاملة.
  • Nano Banana ولّد صورة بجودة برومبت خبير، بدون ما تكتب حرفاً من البرومبت بيدك.
  • Magnific رفع الجودة تلقائياً، والصورة طلعت بحجم ١٠٢٤×١٠٢٤ جاهزة للنشر.
  • برومبت الحركة كُتب وشُغّل، وفيديو طلع بشخصية ثابتة وكاميرا واضحة.
  • أنت في المطبخ تسوي قهوتك، والنظام يشتغل لوحده.

للتوضيح: الحجم النهائي يساوي حجم الصورة اللي دخلت مضروب في معامل التكبير. يعني صورة ١٠٢٤ بكسل مع ×2 تطلع ٢٠٤٨ بكسل، فاختار الدقة والمعامل حسب مكان النشر.

جديد في Figma Weave

لما يضبط معك النظام، تقدر تحوّله لـ Tool، واسمها القديم Design App. تضيف نود Output وتضغط Create tool، ويطلع لك واجهة بسيطة بدون الكانفس، تشاركها برابط مع فريقك أو عميلك، أو تنشرها في Figma Community لو خطتك مدفوعة١٦. ومن يونيو ٢٠٢٦ صارت أدوات Weave تشتغل داخل Figma Design نفسه كنسخة تجريبية١٧، بس للأدوات اللي تطلع صور أو Vector١٦.

اللي يوقفك هو عقلك، مو الأداة. كل ما بنيت نوداً إضافياً، زادت قوة النظام. ما في حدود لما تقدر تبنيه.

إنت القائد. إنت المبدع. إنت المخرج.
Figma Weave هو المصنع، وإنت اللي تصمم خط الإنتاج.

تأمل قبل ما تكمل

  1. لو بنيت سير عمل في Figma Weave لمشروعك، وش المهمة اللي تبغى تشتغل تلقائياً بدون تدخل منك؟

  2. كيف تكتب System Prompt يجعل الـ LLM يكتب برومبتات بأسلوبك البصري تحديداً؟

  3. وش الفرق بين إنتاجك الحالي وإنتاجك لو كان عندك هذا النظام يشتغل في الخلفية؟

خلصت الدليل؟ ارجع للدرس وكمّل من المكان اللي وقفت فيه.
